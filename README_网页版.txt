Project Zero 网页版 49.19.11

推荐使用方式：
1. 将本压缩包完整解压，不要只拖出 index.html。
2. 上传全部文件到 GitHub Pages 等静态网站，保持目录结构不变。
3. 首次进入后点击或按键一次，浏览器才允许播放音乐。

音乐完整性：
- 内含 12 首 BGM，文件名、路径与音频字节均完整保留。
- 第二章关卡页：chapter2_operation.mp3
- 第二章战斗：chapter2_battle.mp3
- 请勿删除 assets/audio/bgm，也不要改变文件名大小写。

本地直接双击 index.html 可以运行核心游戏，但浏览器对 file:// 的缓存、
账号接口和音频策略限制较多；正式测试建议通过 HTTP/HTTPS 部署。
